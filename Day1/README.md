# Day 01 - Python Tasks

Solutions for Day 01 tasks covering basic algorithms, list manipulation, dictionary grouping, and input validation.

## 📌 Tasks Covered

1. **Palindrome Checker:** Determines whether a given string reads the same forwards and backwards.
2. **List Concatenation:** Combines two input lists sequentially.
3. **Alphabetical Name Grouper:** Sorts a list of names and groups them into a dictionary by their starting letter.
4. **User Input Validation (with Bonus):** Validates user name (non-empty, non-numeric) and email syntax using Regular Expressions.

## 🚀 How to Run

Navigate to the project root directory and execute:

```bash
python "Day 01/main.py"
```
