# Day 02 - Python Tasks

Solutions for Day 02 tasks covering string manipulations, sequence search, array filtering, and greedy optimization algorithms.

---

## 📌 Tasks Covered

1. **Vowels Counter:** Counts the total number of vowel characters (`a, e, i, o, u`) in a given string (case-insensitive).
2. **Find Character Index (`'i'`):** Returns all zero-based index locations of the character `'i'` in a string.
3. **All Longest Strings:** Filters an array of strings and returns a new list containing only the longest strings.
4. **Min Boxes for Apples (Bonus):** Solves the resource allocation problem using a **Greedy Approach** to find the minimum number of capacity-constrained boxes required to store a total count of apples.

---

## 💻 Code Overview

### Functions Included:

- `count_vowels(input_string: str) -> int`
- `find_i_locations(input_string: str) -> list[int]`
- `all_longest_strings(input_array: list[str]) -> list[str]`
- `min_boxes_for_apples(apples: list[int], capacity: list[int]) -> int`
